# Boombox songs

Real recorded songs for the garage boombox. They play first, then the game's own made-up band.

To add a song:
1. Put the MP3 in this folder (keep it under about 5 MB; 128 kbps is plenty).
2. Add it to `tracks.json`:

```json
[
  { "file": "smooth-lovin.mp3", "title": "Smooth Lovin", "artist": "Kevin MacLeod (incompetech.com)",
    "license": "CC BY 4.0", "url": "https://incompetech.com/" }
]
```

3. Add the same credit to `CREDITS.md` at the top of the repository.

Only use music that's free to share in a public game: CC0, CC BY (credit it), or the Pixabay Content License.
Not "ND" (no changes) or anything "all rights reserved".
